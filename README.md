## Deskripsi Singkat Proyek

KasirKita merupakan aplikasi berbasis web untuk membantu pengelolaan
transaksi penjualan dan persediaan pada toko pakan.

Aplikasi ini dirancang untuk mempermudah proses kasir, pengelolaan
produk dan stok, serta pencatatan transaksi secara terkomputerisasi.

## Fitur Utama

- Login dan Register
- Hak akses berdasarkan role
- Pengelolaan data produk
- Pengelolaan kategori produk
- Pengelolaan supplier
- Pengelolaan pelanggan
- Transaksi penjualan
- Transaksi pembelian
- Manajemen stok
- Pencarian dan filter produk
- Dashboard dan laporan
- Upload foto produk
