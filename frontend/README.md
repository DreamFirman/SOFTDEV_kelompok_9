# KasirKita — Toko Pakan

Prototype frontend yang mengikuti mockup: Login, Dashboard, Kasir, dan Checkout.

## Menjalankan
1. Pasang Node.js.
2. Ekstrak ZIP dan buka folder `KasirKita-Frontend` di VS Code.
3. Buka Terminal di VS Code, lalu jalankan:
   ```bash
   npm install
   npm run dev
   ```
4. Buka alamat yang muncul di terminal, biasanya `http://localhost:5173`.

## Catatan
Ini prototype frontend. Login belum terhubung ke backend, dan produk/transaksi disimpan lokal di browser (`localStorage`). Data produk dan grafik yang belum berasal dari transaksi adalah data contoh.
